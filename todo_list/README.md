# To-Do List

This is a beginner Python command-line to-do list application.

The user can add tasks, remove tasks, view the current list, and quit the program.

## Features

- Shows all current tasks
- Adds new tasks
- Removes a task
- Shows a message when the list is empty
- Runs until the user chooses to quit

## Skills Practiced

- Python lists
- While loops
- User input
- Conditional logic
- Basic menu system

## How to Run

```bash
python todo_list.py
