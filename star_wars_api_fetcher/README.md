# Star Wars API Fetcher

This is a beginner Python command-line project that connects to the Star Wars API and downloads character data.

The user chooses how many Star Wars characters they want to fetch, and the program prints the character names.

## Features

- Connects to an external API
- Downloads character data
- Reads JSON responses
- Handles HTTP errors
- Fetches multiple pages of API results
- Prints character names

## Skills Practiced

- Python functions
- External APIs
- HTTP requests
- JSON data
- Error handling
- Loops
- User input
