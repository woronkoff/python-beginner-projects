# Rock Paper Scissors

This is a beginner Python command-line game where the user plays Rock, Paper, Scissors against the computer.

The first player to reach 2 wins is the winner.

## Features

- Player chooses rock, paper, or scissors
- Computer randomly chooses rock, paper, or scissors
- Compares both choices
- Tracks player and computer scores
- Ends when one side reaches 2 wins

## Skills Practiced

- Python loops
- Conditional logic
- Random module
- User input
- Score tracking
- Basic game logic

## How to Run

```bash
python rock_paper_scissors.py
