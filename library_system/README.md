# Library System

This is a beginner Python project that uses object-oriented programming to create a simple library system.

The project includes books, availability status, and a library that stores multiple books.

## Features

- Creates book objects with title and author
- Stores whether a book is available
- Allows a book to be checked out
- Allows a book to be returned
- Displays book information
- Stores books inside a library object

## Skills Practiced

- Object-oriented programming
- Classes
- Methods
- Object attributes
- Lists of objects
- Basic search logic

## How to Run

```bash
python library_system.py
