# Card Drawer

This is a beginner Python command-line project that creates a deck of playing cards, shuffles it, and allows the user to draw cards from the deck.

## Features

- Creates a full deck of cards
- Shuffles the deck randomly
- Allows the user to choose how many cards to draw
- Displays each card in a simple visual format
- Removes drawn cards from the deck
- Ends when there are no cards left

## Skills Practiced

- Python functions
- Lists
- Tuples
- Loops
- Random module
- User input
- String formatting

## How to Run

```bash
python card_drawer.py
