# Food Order System

This is a beginner Python command-line food ordering system.

The user chooses a cuisine type, views available meals, selects a meal, and enters the amount they want to order.

## Features

- Shows available meals by cuisine type
- Allows the user to choose a meal
- Allows the user to enter an order amount
- Checks if the selected meal exists
- Prints an order summary

## Skills Practiced

- Python functions
- Lists
- Conditional logic
- User input
- String handling
- Basic menu system

## How to Run

```bash
python food_order_system.py
