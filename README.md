# Python Beginner Projects

This repository contains small Python projects I built while learning programming and software engineering.

These projects are beginner-level, but they show my progress with Python basics such as functions, loops, conditionals, lists, user input, and object-oriented programming.

## Projects

### Card Drawer
A command-line program that creates a deck of cards, shuffles it, and allows the user to draw cards.

### Food Order System
A simple command-line food ordering system where the user can choose a cuisine, view meals, and place an order.

### Rock Paper Scissors
A command-line rock, paper, scissors game where the player plays against the computer.

### Library System
A basic library system using classes to create books and manage availability.

### To-Do List
A simple command-line to-do list application.

### Finance Transaction Analyzer
A command-line program that analyzes a list of financial transactions.

### Star Wars Mini API Project
A small Flask API server and Python client. The server provides character data in JSON format, and the client sends HTTP requests to read and display the data.
