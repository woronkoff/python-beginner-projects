# Finance Transaction Analyzer

This is a beginner Python command-line program that analyzes a list of financial transactions.

Each transaction has an amount and a category. Positive values represent deposits, and negative values represent withdrawals.

## Features

- Prints a summary of total deposits
- Prints a summary of total withdrawals
- Calculates the final balance
- Finds the largest deposit
- Finds the largest withdrawal
- Calculates average deposits
- Calculates average withdrawals
- Uses a simple menu system

## Skills Practiced

- Python functions
- Lists
- Tuples
- Loops
- Conditional logic
- List comprehensions
- Sorting data
- Basic financial calculations

## How to Run

```bash
python finance_transaction_analyzer.py
